# The corpus of an NLP course

The programs here are the ladder of an NLP course taught by the author —
a bigram count, a neural bigram, a character MLP and a GPT (`05_gpt.psk`,
the "course GPT" of the manual and of the experiments) — trained on the
text of the French Code civil. The manual's `corpus` chapter describes
them, `EXPECTED.md` what each produces, and `make corpus`, `make
corpus-gpt` and `make gpt-trained` run them.

## The texts and their licence

- **`data/civil_mots.txt`** (tracked): the words of the Code civil, one per
  line, as the course's first notebook distributes them. It is the
  character vocabulary of the ladder.
- **`data/civil.md`** (fetched, not tracked): the Code civil's text,
  fetched by `data/prepare.py` from the course's site; everything derived
  from it (`bigrams.txt`, `context3.txt`, `vocab.txt`, the `.psk.d` files)
  is regenerated by the same script and ignored by git (`.gitignore`).
- **The Code pénal, the Code du travail and the Code de procédure pénale**
  (fetched, not tracked): the further texts of `experiments/second_corpus.sh`
  and `experiments/further_texts.sh`, on which the certificate is judged
  (the manual's `experiments` chapter), fetched from the course's
  container.

The texts of the French codes are public data published by the Direction
de l'information légale et administrative (DILA) on Légifrance, under the
Licence Ouverte / Open Licence 2.0 (Etalab), which allows their reuse with
the source named. The course's copies are consolidated versions of
2025; `prepare.py` and the experiments' scripts name the files they fetch.
Nothing else in this directory comes from a third party.
